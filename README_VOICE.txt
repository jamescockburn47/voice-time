HOW TO USE VOICE MODE
--------------------------------------------------------------------------------

STEP 1: Install Voice Dependencies (One Time Only)
   Double-click:  install_voice.bat

   Double-click:  🎤 VOICE MODE.bat

   Double-click:  START_HERE.bat
   Choose option 3 (Start VOICE Mode)

--------------------------------------------------------------------------------
HOW VOICE MODE WORKS
--------------------------------------------------------------------------------

NO WAKE WORD - Uses HOTKEY activation instead!

Press and HOLD F13 → Speak → Release → System processes

Alternative: Press Ctrl+Shift+T to toggle recording on/off

--------------------------------------------------------------------------------
EXAMPLE USAGE
--------------------------------------------------------------------------------

1. Double-click: 🎤 VOICE MODE.bat

2. You'll see:
   🎧 Waiting for hotkey... Press F13 or Ctrl+Shift+T

3. Press and HOLD F13 key

4. Say: "Today I need to finish Smith disclosure"

5. RELEASE F13

6. System transcribes and processes automatically!

   You said: Today I need to finish Smith disclosure
   Processing...
   ✓ Planned 1 task

   Ready for next command... (Press hotkey)

7. Press F13 again, say: "Working on Smith disclosure", release

8. Later: Press F13, say: "Done with the disclosure", release

   ✓ Logged 2.5h to Smith v Jones - Document Review

NO TYPING NEEDED!

--------------------------------------------------------------------------------
HOTKEY OPTIONS
--------------------------------------------------------------------------------

Option 1: F13 (Push-to-Talk)
   - Press and HOLD F13
   - Speak
   - RELEASE when done
   - Best for quick commands

Option 2: Ctrl+Shift+T (Toggle)
   - Press once to START recording
   - Speak
   - Press again to STOP
   - Good for longer descriptions

Option 3: Ctrl+Shift+Space (Alternative)
   - Press and HOLD
   - Speak
   - RELEASE
   - Works on all keyboards

--------------------------------------------------------------------------------
F13 KEY ISSUE?
--------------------------------------------------------------------------------

Most keyboards don't have F13!

SOLUTION: Remap another key to F13

Windows:
   1. Download SharpKeys or AutoHotkey
   2. Remap Caps Lock (or another key) to F13
   3. Restart
   4. Use that key for push-to-talk

OR just use Ctrl+Shift+T (works on all keyboards!)

--------------------------------------------------------------------------------
WHY HOTKEY INSTEAD OF "HEY TIMEKEEPER"?
--------------------------------------------------------------------------------

Wake words (like "Alexa" or "Hey Google"):
   ❌ Constantly listening (privacy concerns)
   ❌ High CPU usage
   ❌ False activations
   ❌ Awkward in office

Hotkey activation:
   ✅ Only records when YOU press the key
   ✅ Better privacy
   ✅ Professional
   ✅ Reliable
   ✅ No false triggers

Like a walkie-talkie - press to talk!
