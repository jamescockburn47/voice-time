STEP 1: FIRST TIME SETUP
--------------------------------------------------------------------------------

Option A - EASIEST (One Click):
   Just double-click:  RUN.bat
   
   It will automatically:
   - Install everything needed
   - Download the AI model
   - Create the database
   - Start the application
   - Open your browser

Option B - With Menu:
   Double-click:  START_HERE.bat
   Choose option 1 (First Time Setup)

--------------------------------------------------------------------------------
STEP 2: DAILY USE
--------------------------------------------------------------------------------

EASIEST WAY - Just double-click one of these:

   🚀 CLICK ME TO START.bat    ← Most obvious name!
   
   OR
   
   RUN.bat                      ← Same thing, simpler name

Both do EVERYTHING automatically:
   ✓ Start Ollama (in background)
   ✓ Start the app
   ✓ Open your browser
   ✓ Ready to use!

Wait 5-10 seconds and browser opens to http://localhost:5000

NO TERMINAL WINDOWS TO MANAGE!

--------------------------------------------------------------------------------
ALTERNATIVE FILES
--------------------------------------------------------------------------------

If you prefer more control:

   START_HERE.bat     → Interactive menu (auto-starts Ollama)
   start.bat          → Direct web UI launch (auto-starts Ollama)
   start_cli.bat      → CLI mode (auto-starts Ollama)

All files now automatically start Ollama - no manual terminal needed!

--------------------------------------------------------------------------------
STOPPING THE APPLICATION
--------------------------------------------------------------------------------

When done for the day:
   1. Close browser tab
   2. Press Ctrl+C in the window
   3. Press Y to confirm

That's it!

--------------------------------------------------------------------------------
TROUBLESHOOTING
--------------------------------------------------------------------------------

Q: "Ollama is not installed"
A: Download and install from https://ollama.ai
   Then run RUN.bat again

Q: "Python is not installed"
A: Download from https://www.python.org/downloads/
   Check "Add Python to PATH" during installation
   Then run RUN.bat again

Q: Browser doesn't open automatically
A: Manually open http://localhost:5000

Q: Application won't start
A: Double-click START_HERE.bat and choose option 5 to check status
