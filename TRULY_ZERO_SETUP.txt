--------------------------------------------------------------------------------
TECHNICAL DETAILS
--------------------------------------------------------------------------------

The setup.bat script now:

1. Checks if Python exists
   → If not, calls install_python.bat
   → Auto-installs via winget or direct download

2. Creates venv if missing
   → python -m venv venv

3. Installs all dependencies
   → pip install -r requirements.txt

4. Installs Ollama if missing
   → calls install_ollama.bat
   → Auto-installs via winget or direct download

5. Downloads model if missing
   → ollama pull qwen2.5:1.5b-instruct (1GB)

6. Creates database if missing
   → python run.py --init

ALL AUTOMATIC!

--------------------------------------------------------------------------------
EDGE CASES HANDLED
--------------------------------------------------------------------------------

✅ Python not in PATH after install
   → Refreshes environment variables
   → Asks user to restart terminal if needed

✅ Winget not available
   → Falls back to direct download

✅ Network issues
   → Shows clear error, offers retry

✅ Installation permissions
   → Uses user-level installs (no admin needed)
