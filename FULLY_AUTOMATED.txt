HOW AUTO-INSTALL WORKS
--------------------------------------------------------------------------------

Method 1: Windows Package Manager (winget)
   - Detects if winget is available
   - Runs: winget install Ollama.Ollama --silent
   - Completely hands-free!

Method 2: Direct Download
   - Downloads OllamaSetup.exe from ollama.ai
   - Runs silent installation
   - Cleans up temp files

Method 3: Manual Fallback
   - If both methods fail
   - Opens browser to ollama.ai
   - User clicks one button to download
   - Then returns to app
