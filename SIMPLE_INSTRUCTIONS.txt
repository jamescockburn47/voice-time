--------------------------------------------------------------------------------
HOTKEY EXPLAINED
--------------------------------------------------------------------------------

Ctrl+Space means:
   - Hold down the Ctrl key (left or right)
   - While holding Ctrl, press Spacebar
   - Keep both held while you SPEAK
   - RELEASE both when done speaking

Like a walkie-talkie button!

TROUBLESHOOTING
--------------------------------------------------------------------------------

Q: Ctrl+Space doesn't work
A: Make sure you're in the console window (the black window)
   Try Ctrl+Shift+T instead (toggle mode)

Q: No speech detected
A: Speak louder, check microphone permissions

Q: "Module 'pynput' not found"
A: The system will install it automatically on first run

Q: I prefer typing
A: Choose option 2 (WEB MODE) from the menu instead
